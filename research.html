Research

My research sits where high-performance computing meets computational physics and numerical mathematics: parallel solvers, CFD kernels, and how they behave on unconventional hardware, from wafer-scale engines to RISC-V boards with posit arithmetic. Interests

Software & research artefacts

  • software RBDIAGaussSeidel: A Red-Black Parallel DIA-format Gauss-Seidel Smoother Plugin for OpenFOAM
    Zenodo · 23 April 2026 · MIT licence · doi:10.5281/zenodo.19706031 · code

    A drop-in replacement smoother for OpenFOAM Foundation v13. It runs Gauss–Seidel over matrices stored in diagonal (DIA) sparse format, using red-black ordering to parallelise with OpenMP. On structured hexahedral meshes it improves memory locality and uses less DRAM bandwidth than OpenFOAM's default indirect LDU-format smoother.

Technical reports

During my time at Calligo Technologies (2026), each project came with an internal technical report covering the implementation, profiling results, and numerical comparisons between IEEE 754 and posit arithmetic. These reports cover:

  • Multi-material thermal analysis of a 2-D aluminium + CFRP domain with HYPRE BoomerAMG, on x86 and the UTTUNGA RISC-V board. At tolerances of 1e-14 to 1e-15 the x86 (IEEE 754) run failed to converge, while the posit run on UTTUNGA converged in about 11–12 iterations. (Blog write-up)
  • An OpenMP red-black Gauss–Seidel smoother in OpenFOAM, profiled across grid resolutions with AMD uProf, Intel VTune, Intel Advisor and LIKWID. The code is public as RBDIAGaussSeidel.
  • A Lattice Boltzmann CFD kernel with a physical validation suite (energy decay, mass conservation, L∞ norm, zero-velocity test), in serial and OpenMP versions at single and double precision, benchmarked on UTTUNGA against x86.

The reports themselves are internal and not public.

Theses

  • MSc Using the Cerebras CS3 Dataflow Accelerator for HPC
    MSc in High Performance Computing · EPCC, University of Edinburgh · 2025 · Supervisor: Dr. Justs Zarins · Edinburgh Research Archive

    An implementation of Taylor–Green vortex decay with the Lattice Boltzmann Method on the Cerebras CS-3, written in CSL. The problem had already been parallelised with OpenMP, MPI and CUDA, but not yet on a wafer-scale engine.
